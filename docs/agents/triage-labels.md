# Triage labels

Use this mapping when an engineering skill refers to a triage role.

| Role | GitHub label | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | A maintainer must evaluate the issue. |
| `needs-info` | `needs-info` | More information is needed from the reporter. |
| `ready-for-agent` | `ready-for-agent` | The issue is fully specified for an agent. |
| `ready-for-human` | `ready-for-human` | The issue requires human implementation. |
| `wontfix` | `wontfix` | The issue will not be implemented. |
